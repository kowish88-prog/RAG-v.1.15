Ассистент отвечает на вопросы на основе **RAG** (Retrieval-Augmented Generation). Работает прямо в **Google Colab** и предоставляет веб‑UI на **Gradio**.

> **Примечание:** в бейдже «Open in Colab» замените `<USER>/<REPO>` на ваш GitHub путь.

---

## ✨ Возможности

- **Гибридный поиск**: FAISS (dense) + BM25 (sparse) по базовому корпусу и вашим файлам.
- **Веб‑обогащение**: DuckDuckGo → извлечение текста (trafilatura) с таймаутами и блок‑листом шумных доменов.
- **Загрузка ваших документов**: PDF, DOCX, TXT, MD, HTML → собственный индекс.
- **LLM по желанию**:
  - OpenAI‑совместимые API (включая OpenRouter) — укажи `API key` и (опц.) `base_url`.
  - HuggingFace Inference (укажи HF Token и repo_id модели).
  - Или **строгий режим без LLM** — ответы только цитатами из источников.
- **Управление контекстом**: очистка чата, стоп длительного запроса.
- **Подсветка цитат** и список источников.
- **Экспорт**: DOCX‑отчёт и ZIP с исходными страницами.
- **Гибкий охват тем**: по умолчанию — отвечает на любые вопросы. Тумблер «Ограничивать тематику ИИ» включает режим «только про AI/цифровые технологии».

```
Вопрос ─▶ Санитайзер ─▶ (опц.) Веб‑обогащение ─▶ Индексы: FAISS + BM25
                                    │
                                    └── Блок‑лист доменов, таймауты

FAISS/BM25 топ‑чанки ─▶ (опц.) LLM (OpenAI/HF) ─▶ Форматированный ответ с цитатами и источниками
                                   │
                                   └── Строгий режим без LLM (только цитаты)

Экспорт: DOCX отчёт, ZIP источников
```

## 🚀 Быстрый старт (Colab)

1. Открой `colab.ipynb` (по бейджу **Open in Colab** сверху).
2. Запусти единственную ячейку — поднимется Gradio‑интерфейс (в конце появится ссылка **share**).
3. (Опционально) во вкладке **Настройки LLM** укажи:
   - *OpenAI‑совместимые*: `API Key` (и при необходимости `Base URL`).
   - *HuggingFace Inference*: `HF Token` + `repo_id` (например, `HuggingFaceH4/zephyr-7b-beta`).
4. Загрузите свои документы (PDF/DOCX/TXT/MD/HTML) → нажмите **«Добавить в индекс»**.
5. Задавайте вопросы. Для универсального режима оставьте тумблер **«Ограничивать тематику ИИ»** выключенным.

> Совет: если ответа нет — включите **«Обогащать индекс из веба»**, понизьте **порог релевантности** или уточните запрос.

## ⚙️ Элементы UI

- **Ограничивать тематику ИИ** — фокусирует поиск на AI/цифровых темах.
- **Обогащать индекс из веба** — вручную подтягивает свежие источники.
- **Отвечать только по моим документам** — игнорирует базовый/веб‑корпус.
- **Top‑K** — сколько чанков попадёт в ответ.
- **Вес свежести (λ)** — усиливает свежие источники.
- **Макс. возраст (мес)** — отсечь старые источники.
- **Порог релевантности** — снизьте, если отклик пустой.
- **⏹️ Стоп** — прерывание долгого запроса.
- **🧽 Очистить чат** — сброс контекста.
- **Скачать отчёт (.docx)** — экспорт диалога.
- **Скачать источники (ZIP)** — HTML страниц, использованных в ответе.
